# ABHAY VERMA Portfolio Website

Modern AI and data science personal portfolio built with React, Tailwind CSS, Framer Motion, and Vite.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production output is generated in `dist/`.

## Edit Content

Most editable portfolio details live in:

```text
src/data/portfolio.js
```

Update profile links, contact details, project cards, certifications, education, experience, achievements, and repository placeholders there.

## Image Placeholders

The profile image, project screenshots, analytics dashboard previews, and Streamlit app screenshots are intentionally blank placeholder panels for future uploads.
